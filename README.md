# ScaleX - Insights & Blogs Page

A clean, modern, dark-themed responsive blog and insights landing page built with semantic HTML5 and CSS3. The page features a dynamic typography layout using Google's _JetBrains Mono_ font, interactive nav elements, category filters, and card layouts for featured blog posts.

---

## 🚀 Live Demo

- **Live URL:** <b>[Click to View](https://scalex-peach.vercel.app/)</b>

---

## ✨ Features

- **Modern Dark UI:** Stylish dark color palette (`#000000`, `#0d0d0d`, with accent orange `#FC460B`).
- **Typography:** Uses Google Font `JetBrains Mono` for a clean, developer-focused aesthetic.
- **Navigation Bar:** Branding area, smooth link styling with hover effects, and a primary CTA button.
- **Category Filter Bar:** Filter pill buttons (All, Tech, SaaS, Marketing) to simulate dynamic content filtering.
- **Card-Based Blog Grid:** Modern layout for articles featuring image previews, tags, titles, and publishing dates.
